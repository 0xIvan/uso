Uso

A menu bar utility for viewing remaining Codex and Claude subscription usage.
Independent software; not affiliated with or endorsed by OpenAI.

REQUIREMENTS
macOS 13 or newer, on Apple Silicon or Intel.
A local Codex sign-in with a ChatGPT account and readable credentials in
~/.codex/auth.json. API-key-only sign-in and Keychain-only credentials are
not supported for Codex. Claude requires a Claude Code subscription sign-in.
Uso reads Codex credentials without modifying them. Claude access tokens renew
automatically through the shared Claude Code login; renewal updates that store.

INSTALL
1. Open the DMG and drag Uso into Applications.
2. Eject the disk image.
3. Open Uso from Applications. Its rings appear in the menu bar;
   it does not open an ordinary window or appear in the Dock.
4. Sign in to Codex if needed, then click the rings and choose Refresh.

Open Settings from the menu to choose Codex and Claude. Each provider has one
icon: weekly on the outer ring, 5-hour on the inner. Enabled providers appear
side by side. Green means on pace,
yellow warns within 5 percentage points over pace, and red means more than
5 points over pace or exhausted. Gray indicates unavailable usage or pace.
Codex and Claude refresh every five minutes. Failed requests clear
the displayed usage. Uso does not show cached readings or read Codex logs.
Claude requires a subscription sign-in through Claude Code.

START AT LOGIN (OPTIONAL)
Open Uso’s Settings and enable Open at login. Disable it to stop opening Uso
automatically when you sign in. If macOS requires approval, Uso opens Login
Items in System Settings; allow Uso there, then return to Uso’s Settings.

UPDATE
Open Settings from Uso's menu, then choose Check for Updates…
If a published update is available,
Sparkle shows its details and lets you install it and relaunch Uso.
Background update checks and unattended installation are disabled.
Older Uso builds without this button need one manual update: quit Uso, open the
new DMG, and replace Uso in Applications. You do not need to delete it first.
Draft and prerelease versions are excluded from in-app updates.

BUNDLE ID TRANSITION
Uso now uses com.ivan.uso. Older local.codex.usage-rings builds need a manual
replacement even if they have Check for Updates. Before replacing, note whether
Open at login is enabled, then disable it in the old app to remove its old
registration. Quit Uso and replace it in Applications. Settings and notification
comparison history are copied automatically; your provider sign-ins are unchanged.
Enable Open at login again if it was on, and allow macOS notifications when asked.
The old update feed stays on 0.2.10; future new-ID builds use a separate feed.

REMOVE
Quit Uso, remove it from Login Items if added, then move the app to Trash.
Your Codex login and usage data are left untouched.
If you previously installed from source using tools/install.sh, first
run tools/uninstall.sh from that source checkout to remove its LaunchAgent.

TROUBLESHOOTING
If no rings are visible, check for menu bar space next to the camera notch.
If usage is unavailable, open Codex and sign in again, then refresh Uso.
Uso reads the Codex credential file but cannot renew an expired Codex token.
If Codex stores credentials only in Keychain, Uso cannot read them.
The upstream usage endpoints can change and interrupt Uso.
A custom CODEX_HOME set only in your shell is not inherited by Finder;
normal installation expects ~/.codex.

Uso automatically renews expired Claude access tokens and refreshes after wake.
If renewal credentials are rejected, run claude auth login, then click Refresh.
Temporary network or lock contention errors retry automatically.
Rate-limited Claude requests retry after five minutes.

CLAUDE INTEGRATION STATUS
Claude monitoring is experimental; automatic renewal updates shared credentials. Permission for this usage-only
integration under Anthropic's rules for subscription credentials has not been
established. Read-only credential access does not resolve that policy question.
Provider changes may interrupt Claude support. See:
https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use
